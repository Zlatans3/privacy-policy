2 Hvilke data vi indsamler

Når du bruger Flotmand, indsamler vi følgende oplysninger:

  • Navn og profilbillede — fra din Google-konto ved login
  • E-mailadresse — fra din Google-konto ved login
  • Bruger-ID — et unikt ID genereret af Firebase til din konto
  • Enheds-token — til udsendelse af push-notifikationer via Firebase Cloud Messaging
  • Begivenhedsdata — begivenheder du opretter eller deltager i, herunder titel, beskrivelse og tidspunkt
  • Stemmedata — dine stemmer og reaktioner på begivenheder

Vi indsamler ikke din lokation. Kortfunktionalitet håndteres udelukkende lokalt på din enhed.

3 Formål og retsgrundlag

Vi behandler dine data til følgende formål:

Formål Retsgrundlag
Oprettelse og administration af din konto Opfyldelse af aftale (GDPR art. 6, stk. 1, litra b)
Visning af begivenheder og profiler Opfyldelse af aftale
Afsendelse af push-notifikationer Samtykke (GDPR art. 6, stk. 1, litra a)

4 Tredjeparter

Vi anvender følgende tredjepartstjenester, som kan modtage dine data:

  • Google Firebase (Firebase Auth, Firestore, Cloud Messaging) — databehandling sker inden for EU/EØS eller med passende garantier. Googles privatlivspolitik
  • Google Sign-In — til autentifikation
  • Google Maps — til visning af kort. Kortdata behandles lokalt og sendes ikke til vores servere

5 Opbevaring af data

Dine data opbevares så længe din konto er aktiv. Du kan til enhver tid anmode om sletning af din konto og alle tilhørende data.

Data slettes inden 30 dage efter anmodning.

Anmod om sletning af konto

5b Sletning af specifikke data (uden kontosletning)

Du kan anmode om sletning af bestemte data uden at slette din konto. Følgende datatyper kan slettes separat:

  • Begivenhedsdata — begivenheder du har oprettet eller deltaget i
  • Stemmer og reaktioner — dine stemmer på begivenheder
  • Enheds-token — dit push-notifikationstoken (deaktiverer notifikationer)

Angiv i din besked hvilke data du ønsker slettet. Data slettes inden 30 dage efter anmodning.

Anmod om sletning af specifikke data

6 Dine rettigheder

Under GDPR har du ret til at:

  • Indsigt — få oplyst hvilke data vi behandler om dig
  • Berigtigelse — få rettet ukorrekte oplysninger
  • Sletning — få slettet dine data ("retten til at blive glemt")
  • Dataportabilitet — modtage dine data i et maskinlæsbart format
  • Indsigelse — gøre indsigelse mod behandling
  • Klage — indgive klage til Datatilsynet

For at udøve dine rettigheder, kontakt os på zeefmusic@gmail.com.

7 Sikkerhed

Vi anvender Firebase's sikkerhedsinfrastruktur til at beskytte dine data, herunder kryptering under transport og i hvile.

8 Ændringer til denne politik

Vi kan opdatere denne privatlivspolitik. Ved væsentlige ændringer vil du blive notificeret via appen. Den seneste version er altid tilgængelig via appen og Play Store.
